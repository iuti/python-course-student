## Colabとの違い

Colabではセルごとに実行していました。VS Codeでは、基本的に`.py`ファイルを上から最後まで実行します。

編集したら、次の順番を意識しましょう。

1. 保存する
2. 実行する
3. ターミナルの結果を読む
4. 必要ならコードを直す

## 進め方

ファイル名の番号順に進めます。コードを実行する前に、表示結果を予想してください。
