## 01_count_total.py

| 問題 | 答え |
|---|---|
| 問題1 | 合計`399`、平均`66.5`。`/`の答えは小数（`20.0`のように`.0`が付くこともある） |
| 問題2 予想 | `4`（72, 88, 60, 95） |
| 問題2 自力 | `low_count`は`1`（39のみ）。条件は`score < 40` |
| 問題3 予想 | 最高点`95`、最低点`39` |
| 問題3 自力 | `print("平均:", sum(scores) / len(scores))` |

**つまずき**：`count = 0`をfor文の中に書いて、毎回0に戻ってしまう。「箱はループの前に1回だけ用意する」と強調する。

## 02_find_max.py

| 問題 | 答え |
|---|---|
| 問題1 | 入れかえは2回：`40 → 120 → 200` |
| 問題2 | `min_hp = enemy_hps[0]`、条件を`hp < min_hp`にする → `40` |
| 問題3 | 表示は`0`。どのHPも0より小さくないので一度も入れかわらない。最初の値は`enemy_hps[0]`にする |
| 問題4 | `200`と`40`。自分の答えと一致すればOK |

**ねらい**：「最初の値をリストの先頭にする」理由を、問題3の失敗から自分の言葉で説明させる。ペアで説明し合う時間を2分取るとよい。
