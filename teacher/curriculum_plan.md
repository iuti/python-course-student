# カリキュラム計画：リストの後（第7回〜第16回）

講師用の計画書です。`teacher`ブランチで管理し、`main`には入れません。

## これまでに学んだこと（前提）

| 回 | 内容 |
|---:|---|
| 第1回 | `print()`・変数・`input()`・`int()` |
| 第2回 | `if`・`elif`・`else`、比較演算子 |
| 第3回 | `for`文・`range()`・合計の計算 |
| 第4回 | `while`文・カウント |
| 第5回 | （既存の回） |
| 第6回 | VS Codeへの移行、リストの基本（作成・添字・変更・`len()`・`for`） |

## 全体の方針

- **題材はゲームで統一**：敵のHP、アイテムバッグ、パーティー、ガチャ。第16回でテキストRPGバトルを完成させる。
- **毎回同じ型**：復習（予想）→ 新しい文法（予想→実行）→ エラー修正 → 自力課題 → トレース → 振り返り。
- **ペアで役割交代**：「予想を説明する人」と「実行して確認する人」。
- **まだ教えていない文法は使わない**：f文字列・`+=`・`break`・`enumerate()`は使わない（`+=`は第11回の関数で導入）。合計は`total = total + x`の形を続ける。
- `main`（生徒用）には模範解答を入れない。解答は`teacher`ブランチの`teacher/`で管理する。

## 単元の流れ

```text
リストの基本(6)
  └─ リストを変化させる(7) ── リストを集計する(8) ── 添字で使いこなす(9)

              └─ 関数①(11) ── 関数②(12)
                    └─ 辞書(13) ── 2次元リスト(14)
                          └─ 総合制作：テキストRPGバトル(15・16)
```

### 補足

- **Gitを教える場合**：生徒用READMEに「Gitを習った後」とあるので、第10回か第11回の冒頭15分に`git clone`・`git pull`を入れると、以降の教材配布が楽になる。
- **進度調整**：第9回が難しければ、第10回の前半を第9回の復習に充てる。第10回はつまずきにくく、遅れの回収に向く。
- **文字列の扱い**：`for 文字 in "文字列"`や`.split()`は第10回以降の発展課題として小出しにする（独立した回は作らない）。
