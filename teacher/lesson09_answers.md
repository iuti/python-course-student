## 01_range_len.py

| 問題 | 答え |
|---|---|
| 問題1 | `len(party)`は`3`、`i`は`0, 1, 2`。`0 Hero` / `1 Mage` / `2 Knight` |
| 問題1 自力 | `print(i + 1, "番目:", party[i])` |
| 問題2 | `[50, 20, 80]`のまま変わらない |
| 問題3 | `[60, 30, 90]` |
| 問題3 自力 | `hps[i] = hps[i] * 2` → `[120, 60, 180]` |
| 問題4 | どちらも`Knight`。`party[-2]`は`Mage` |

**ねらい**：問題2が今日の山場。「hpはコピー」という説明は、カードのコピーを渡すたとえ（コピーに書き込んでも元のカードは変わらない）が中学生に通じやすい。

## 02_two_lists.py

| 問題 | 答え |
|---|---|
| 問題1 | 3行目は`Golem HP: 120` |
| 問題2 自力 | `if hps[i] < 50:` → Slime、Bat |
| 問題3 | `max_index`は`3` → `一番強い敵: Dragon HP: 300` |
| 問題3 自力 | `min_index = 0`、条件`hps[i] < hps[min_index]` → `Slime HP: 30` |
| 問題4 | `IndexError: list index out of range`。`i`が`4`のとき。添字は`0`〜`3`まで。`+ 1`を消す |

**つまずき**：`max_index = i`ではなく`max_index = hps[i]`と書いてしまう。「今は何番目かを覚えたい」と変数名の意味に立ち返らせる。
