# VS Codeの準備

## 必要なもの

次の3つをインストールします。

1. Python 3
2. Visual Studio Code
3. VS CodeのMicrosoft Python拡張機能

## 動作確認

VS Codeで`00_check.py`を開き、右上の三角形ボタン **Run Python File in Terminal** を押します。

```python
print("VS Codeの準備OK！")
```

画面下部へ次のように表示されれば準備完了です。

```text
VS Codeの準備OK！
```

## 実行できないとき

### Pythonを選択する

1. `Ctrl + Shift + P`を押す
2. `Python: Select Interpreter`と入力する
3. インストールしたPython 3を選ぶ

### 実行ボタンがない

- ファイル名が`.py`で終わっているか確認する
- MicrosoftのPython拡張機能が入っているか確認する
- VS Codeを一度閉じて開き直す
