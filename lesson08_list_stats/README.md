## 集計の3つの型

```python
# 合計する
total = 0
for x in リスト:
    total = total + x

# 数える
count = 0
for x in リスト:
    if 条件:
        count = count + 1

# 集める
result = []
for x in リスト:
    if 条件:
        result.append(x)
```

どれも「ループの前に箱を用意する → ループの中で箱を更新する → ループの後で表示する」という形です。
