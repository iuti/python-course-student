# 第7回：リストを変化させよう

授業時間：60分　／　テーマ：アイテムバッグとショップ

## 今日のゴール

- 空のリスト`[]`を作れる
- `append()`でリストの最後に値を追加できる
- `in`・`not in`でリストの中に値があるか調べられる
- `remove()`でリストから値を取り除ける
- `while`文とリストを組み合わせて、何度でも追加できる

## 今日の新しい命令

| 書き方 | 意味 | 例 |
|---|---|---|
| `[]` | 空のリスト | `bag = []` |
| `リスト.append(値)` | 最後に追加する | `bag.append("Potion")` |
| `値 in リスト` | 入っていれば`True` | `"Key" in bag` |
| `値 not in リスト` | 入っていなければ`True` | `"Key" not in bag` |
| `リスト.remove(値)` | 最初に見つかった1つを取り除く | `bag.remove("Potion")` |

`True`は「正しい」、`False`は「正しくない」という意味です。`if`文の条件は、この`True`か`False`で動いています。

## エラーが出たら

1. ターミナルの**最後の行**を読む
2. 書かれている行番号の行を見る
3. その1行前も確認する

| エラー名 | よくある原因 |
|---|---|
| `ValueError` | `remove()`しようとした値がリストにない |
| `AttributeError` | `append`のつづりが間違っている |
| `NameError` | 変数名のつづりが間違っている・まだ作っていない |
