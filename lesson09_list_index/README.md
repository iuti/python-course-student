## 2種類のfor文

```python
hps = [50, 20, 80]

# 中身を1つずつ取り出す（読むだけのとき）
for hp in hps:
    print(hp)

# 添字を1つずつ取り出す（書き換えるとき・何番目か知りたいとき）
for i in range(len(hps)):
    print(i, hps[i])
```

| 使いたい場面 | 書き方 |
|---|---|
| 中身を表示する・合計する | `for hp in hps:` |
| 中身を書き換える | `for i in range(len(hps)):` |
| 何番目かを知りたい | `for i in range(len(hps)):` |
| 2つのリストを同時に使う | `for i in range(len(hps)):` |

`len(hps)`が3なら、`range(len(hps))`は`range(3)`と同じで、`i`には`0, 1, 2`が入ります。

## エラーが出たら

| エラー名 | よくある原因 |
|---|---|
| `IndexError` | 添字がリストの長さ以上になっている（`range(len(x) + 1)`など） |
| `TypeError` | `for i in len(x):`のように`range()`を書き忘れている |
